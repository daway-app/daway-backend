معاينة تسجيل الصيدليات الذاتي

ثلاث حالات رئيسية: التسجيل → انتظار الموافقة → تفعيل الأدمن

1 صفحة التسجيل — بدون كلمة مرور ولا معرّف
💊

إنشاء حساب صيدلية

عبّئ بيانات صيدليتك، وبعد موافقة الإدارة رح يظهرلك معرّف الدخول.

💡 بعد إنشاء الحساب لا يظهر أي معرّف — بيانات الدخول (Pharmacy ID + كلمة المرور) رح تُرسل لك عبر رسالة نصية فور موافقة الإدارة.
عندك حساب بالفعل؟ تسجيل الدخول
2 صفحة الدخول — بعد التسجيل (رسالة انتظار)
🔐

تسجيل الدخول

✅ تم إنشاء حساب صيدلية النور بنجاح.
الحساب بانتظار موافقة الإدارة، وبعد الموافقة رح تصلك رسالة ببيانات الدخول.
ليس لديك حساب؟ إنشاء حساب صيدلية

5 تدفق الـ API (للموبايل)

① تسجيل جديد (201)

POST /api/register/pharmacy
{
  "pharmacy_name": "صيدلية النور",
  "phone": "0599000000",
  "address": "شارع فلسطين",
  "region": "الرمال"
}

→ Response: { "success": true, "message": "..." }
   (لا يوجد pharmacy_id في الرد)

② أول login قبل التفعيل (403)

POST /api/login/pharmacy
{ "pharmacy_id": "PH-A7K2", "password": "..." }

→ Response (403):
{
  "message": "Account is inactive",
  "code": "account_inactive",
  "credentials": {
    "pharmacy_id": "PH-A7K2",
    "password": "xK9mP2vLqR5..."
  }
}
